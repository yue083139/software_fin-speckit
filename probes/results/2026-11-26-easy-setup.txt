# easy-setup 探針結果（2026-11-26）

## ③ winget 安裝後同一 PowerShell 行程刷新 PATH（已執行）
指令（PowerShell 5.1）：
  $env:Path = ($env:Path -split ';' | Where-Object { $_ -notmatch 'cloudflared' }) -join ';'
  $before = [bool](Get-Command cloudflared -ErrorAction SilentlyContinue)
  $env:Path = [Environment]::GetEnvironmentVariable('Path','Machine') + ';' + [Environment]::GetEnvironmentVariable('Path','User')
  $after = Get-Command cloudflared -ErrorAction SilentlyContinue
原樣輸出：
③ 移除 cloudflared 目錄後 Get-Command 找得到：False
③ 以 Machine＋User 登錄值刷新 $env:Path 後：True → C:\Program Files (x86)\cloudflared\cloudflared.exe
③ PowerShell 5.1.26100.9818
