# 派單定式

**規矩一句話**：凡向 subagent 派評審，prompt 按下面骨架寫，**每槽有內容或明寫「無」**；寫不出某槽等於活沒做完，先補稿再派，不是把槽改成問句。

**為什麼是定式不是禁令**：`CLAUDE.md` 基本紀律「未決事項自己定」是禁令，禁令擋不住慣性；定式是正向的，照著填就不會外包。

```
## 0 抬頭（治：規格文件組不同步／評審對象漂）
評審對象＝<規格文件組路徑> @ <vX.Y>（各件抬頭版本一致；OpenSpec＝proposal/design/specs/tasks，Spec Kit＝spec/plan/tasks/diagrams）
基線＝dev <sha>；本輪 commit＝<git log 範圍>（評審員自己 git show，不看我的描述）
通道＝<紅隊|架構|finder-tail>；不告知輪次、不告知其他通道結論
約束＝禁改工作樹；禁跑會呼叫雲端 API 的指令（門禁由主 agent 統一真跑並附輸出）
知識時點＝<日期>

## 1 範圍
本輪＝<定點：僅本輪改動行 | 全卡掃：規格文件組＋門禁腳本現狀>
本卡至今全卡掃次數＝<n>（S 檔第 2 輪＝末輪，若至今為 0 ⇒ 本輪必須全卡掃；B 檔提案輪即全卡掃；B 檔實作輪與 C 檔＝定點，範圍＝該 PR 的 diff）

## 2 斷言清單
提案輪：逐條取自證偽欄標「屬取捨」的決策；實作輪：取自本輪 diff 引入的新決策
A-n | 結論＝<X> | 稿內落點＝<file:line>（稿裡沒有＝沒做完） | 理由＝<Y> | 已自對碼＝<輸出>（貼輸出不貼指令） | 請證偽
本段禁止問句（發前 grep `會不會|是否|要不要|有沒有|\?|？` 零命中）

## 3 上輪藥方落點
藥方 → 落點 commit/file:line → 自證指令與輸出
落點集合由開方人獨立 `git grep -n <模式> -- :/` 求差集（`-- :/` 不能省：在子目錄裡跑會靜默漏掉大半個倉；未 `git add` 的新檔加 `--untracked`），自報清單只作閱讀輔助；不入庫的記憶檔與 `.env` 點名掃

## 4 有意不改
<引用點> | 不改理由 | 或「無」

## 5 未決呈裁
<事項> | 我傾向 X | 阻塞/不阻塞 | 呈負責人——評審員只核「傾向 X 與稿內其餘是否自洽」

## 6 退出條件
本輪放行判據（發前寫死）＝<例：0 阻斷；重要項全部有稿內落點>
輪次上限按 `CLAUDE.md` 分檔表，觸頂即停；上限後只有「淨回歸／使原修復失效／假綠掩蓋原病」三類可阻塞，其餘進 followup

## 7 返回格式
一句話結論；每條發現五行：哪兒（file:line）／什麼錯／會怎樣（具體後果）／怎麼修／證據（指令 → 輸出）；
編號與符號只進「哪兒」「證據」兩欄，術語首現即解釋；「外包檢查」：指出 §2 哪條其實是問句或稿內無落點；「我查閱的檔案」；
末行 `CLEARED` / `NOT CLEARED(nB/nM/nm)`（B＝阻斷 M＝重要 m＝次要）。
同形副本在 `.claude/agents/finder-tail-{red,arch}.md`（改一處就要同批改）

## 8 預算
讀取面＝<定點：git diff <a> <b> + 上輪藥方表 + 被訂正字面量的 git grep 全集 | 全卡掃：規格文件組＋門禁腳本現狀>
返回長度＝<n 行上限>（定點 8–20 行，全卡掃 40–60 行）
續用還是新起＝<續用理由 | 新起>
```

## 發前自檢

任一不過不發：①§2 問句 grep 零命中；②§2 每條「稿內落點」能 `sed -n` 出對應句；③§0 版本標記各件一致；④§2 每條「已自對碼」欄是輸出，不是指令。
