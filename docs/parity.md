# 兩組功能一致協議（parity）

> 本檔在 OpenSpec 組與 SpecKit 組兩個 repo **逐位元組相同**（判據：`make gate-parity SIBLING=<另一 repo 路徑>`）。
> 對應需求 P-03：兩組產出的系統功能要一致，實作期間任何改動要與另一組討論。

## 1. 規則

1. **凡改使用者可感知行為的卡**（OpenSpec 的 change／Spec Kit 的 feature），開卡時先在本檔 §4「功能清單」登記或改行，並在 §5「變更紀錄」加一行；**兩個 repo 同批改本檔**（各開一個 PR，PR 描述互相連結）。
2. 一邊的規格先定稿，另一邊**照同一行為寫自己工具格式的規格**，不互抄檔案——兩組的評分各看自己工具的產物。
3. 行為以本檔＋`docs/requirements.md` 為準；兩組各自的規格與本檔衝突時，**改規格**，或回本檔改行並通知另一組。
4. 不改行為的卡（文件、重構、門禁）不必登記。

## 2. 共用技術選型（兩組相同，降低 Demo 與比對成本）

| 層 | 選型 | 理由（屬取捨） |
|---|---|---|
| 後端 | Python 3.12、FastAPI、WebSocket、uv 管理依賴 | 階段同步需要伺服器推播；與門禁腳本同語言 |
| 試算表 | openpyxl 讀寫 xlsx | 保留原檔格式與合併儲存格，回寫填空格後仍可匯回 Google Sheets |
| 前端 | React＋Vite＋TypeScript，npm 管理 | 老師端與學生端同一套元件，以路由區分 |
| 儲存 | 伺服器記憶體＋JSON 快照（`data/`，不入庫） | 本機模擬即可（需求 §1），不引入資料庫 |
| 執行 | 本機單一伺服器；多個瀏覽器分頁模擬老師與各組 | 需求明示不必架設對外伺服器 |

選型由第一張功能卡的 design／plan 正式寫入；若一組要偏離，先改本表並通知另一組。

## 3. 未決呈裁

| 事項 | 我傾向 | 阻塞否 |
|---|---|---|
| Guided Notes 匯入／匯出管道 | **xlsx 檔往返為主**：老師在 Google Sheets「檔案→下載→xlsx」匯入；系統輸出填好答案的 xlsx，老師以「檔案→匯入→取代試算表」放回 Google Sheets。另支援貼上「知道連結者可檢視」的 Sheets 網址直接匯入（`/export?format=xlsx`，免憑證，已實測可下載範本）。**直接寫回 Google Sheets** 需 OAuth／服務帳戶，列為選做卡，憑證只走環境變數 | 阻塞匯入卡的 design，不阻塞骨架 |
| 搶答成功的判定單位 | 以**題**為單位：每題最先送出的組別得該題；題組（X-01）以整組為單位同時送出、同時判定 | 阻塞作答卡 |
| 「最快」的時間基準 | **伺服器接收順序**（單一事件迴圈內遞增序號），不採信客戶端時間戳 | 阻塞作答卡 |
| 同一組多位學生 | 一組一個「組帳號」分頁即可；同組多分頁時，**第一次送出即鎖定**該組該題答案 | 不阻塞 |

## 4. 功能清單（建議拆卡順序；兩組卡名一致，便於對照）

| 卡名 | 涵蓋需求 | 摘要 | OpenSpec 狀態 | SpecKit 狀態 |
|---|---|---|---|---|
| `app-skeleton` | R-01、R-11 | 前後端骨架；老師／學生（選組別）進場；活動階段狀態機（準備→搶答中→已結束）與 WebSocket 全員同步 | 未開 | 未開 |
| `guided-notes-import` | R-02、X-01 | 匯入 xlsx／Sheets 連結；以表頭與合併範圍動態辨識題號、題組與作答格；題數與原檔一致 | 未開 | 未開 |
| `buzz-answering` | R-03、R-06、R-07、R-09、R-10 | 老師開啟／結束搶答；各組作答送出；伺服器判定最快組；結束前作答隔離 | 未開 | 未開 |
| `results-view` | R-04、R-08 | 老師即時看作答狀況與結果；學生於結束後看結果 | 未開 | 未開 |
| `guided-notes-export` | R-05 | 把每題搶答成功的答案寫回原檔作答格（題組寫在「（k）」之後），輸出 xlsx | 未開 | 未開 |
| `csv-export` | X-02 | 題號、組別、答案、搶答順位匯出 CSV | 未開 | 未開 |
| `fair-ranking` | X-03 | 公平順位機制（候選：已得分組別在下一題延遲生效或降序） | 未開 | 未開 |

狀態值：未開／提案中／實作中／已合入。
